# ALO — layouts, drawing sets and sheet sets for AutoCAD

**[Download the latest version](https://github.com/arcthanhbinhtran-ai/alo/releases/latest)** · **[Website](https://arcthanhbinhtran-ai.github.io/m5studio/chi-tiet.html?id=alo&lang=en)** · by [M5 STUDIO](https://arcthanhbinhtran-ai.github.io/m5studio/?lang=en)

For anyone producing multi-sheet drawing sets. Free, for AutoCAD 2015 – 2027.

- Scan drawing frames in Model space and create layouts in bulk
- Drawing list: number, title, scale, date, groups — write back to the drawings
- Link title block attributes to Sheet Set fields: edit once, every sheet follows
- Create, read and edit real Sheet Set Manager files (`.dst`), add sheets, Excel round-trip
- Print the whole set to one PDF with bookmarks per group
- Built-in update check

> **Interface language:** Vietnamese for now. An English interface is planned.

## Install

1. Download the zip from [Releases](https://github.com/arcthanhbinhtran-ai/alo/releases/latest) and **unzip** it.
2. Close AutoCAD, double-click **`ALO_GUI_vX.Y_CaiDat.exe`** in the unzipped folder.
3. If Windows shows “Windows protected your PC”, click **More info → Run anyway** (the installer is not code-signed yet).
4. Open AutoCAD: a new **ALO** ribbon tab appears (or type `ALO`).

This repository only hosts the release files.
